# Chile — datos.gob.cl

**Source:** https://datos.gob.cl/dataset/

No dedicated statistics API is known to exist for census-style data. Datasets
are browsed and downloaded manually from Chile's open-data portal
(datasets vary in format — CSV/XLSX/SHP depending on publisher agency).

**Auth / token:** none available. `api_keys.json` has no entry for Chile.

**Data format:** varies by dataset; check each dataset's page on the portal
for its export formats.

See `api_info.txt` (gitignored, not committed) in this directory for the raw
notes this README was derived from.
